1. Visão geral
Sistema de gestão web para o Mercadão dos Óculos de Crissiumal (loja de óculos de
grau e solar, com serviço de ótica), no mesmo estilo do Khaus Gestão.
Stack: React (Vite) + Supabase + publicação no GitHub Pages
Login por usuário: cada vendedor entra com o próprio login (o vendedor da venda
é preenchido automaticamente pelo login)
Construção em etapas: primeiro a fundação (estrutura + banco + login + layout +
dashboard + configurações), depois cada módulo separadamente
Módulos
Dashboard — painel que resume os dados de todos os módulos
Vendas diárias — lançamento das vendas de cada vendedor, com histórico por dia
Resumo do período — total das vendas/contas lançadas num período escolhido
Vendedores e comissões — quanto cada um vendeu e a comissão no período
Cobranças — inadimplentes, alimentado pelo relatório de boletos da cooperativa
Configurações — nº inicial da O.S., cadastro/configuração de vendedores, formas
de pagamento# Gestao-Mercadao-dos-Oculos-
